# Deploy the MVP on Polygon

The Competition Market contracts will launch on Polygon PoS / Polygon Chain, using Amoy for testing and mainnet chain ID `137` for production. Polygon was selected over BNB Chain, Arbitrum, Solana, and Monad because it combines EVM tooling, inexpensive deterministic finality, stablecoin and gas-sponsorship support, and a proven prediction-market contract pattern; the trade-off is accepting Polygon's security model instead of Ethereum-rollup settlement and postponing the higher-throughput but separate Solana program stack.
